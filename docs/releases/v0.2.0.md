# Task Continuum v0.2.0

Windows x64 release containing the changes since v0.1.1, including the desktop
update experience, compact chat and improved cross-device session workflows.

**Unsigned release - manual installation required.** Code signing is not yet
configured. Windows may show an unknown-publisher or SmartScreen warning. Verify
the downloaded files against `SHA256SUMS.txt`; a matching checksum is not a
publisher signature. This release does not enable automatic installation.

## Highlights

- **Desktop updates:** compact titlebar update status, an About and updates
  panel, background update support for eligible signed installer builds, and a
  one-click restart action. Unsent drafts, active Host work and file transfers
  block an unsafe restart. Ordinary quitting never installs an update.
- **Compact chat:** combined workbench/chat header, grouped routine tool
  activity, more space for answers, a refreshed light/dark palette and responsive
  fullscreen layout.
- **Session navigation:** multiple sessions per task, machine aliases, remembered
  task/session selections and open task tabs, keyboard shortcuts, and retained
  loaded history when switching sessions.
- **Agent Host connectivity:** explicit AHP 1.0.0, 0.10.0 and 0.9.0 negotiation,
  reduced authorization/refresh overhead, isolated terminal subscriptions, and
  bounded large-history support.
- **Chat content and files:** math rendering, source-owned file links, previews
  for sent screenshots, a 12,000-character message limit and trusted-device file
  transfer MCP tools.
- **Durable device trust:** unchanged trusted relationships no longer need daily
  public invitation renewals. Short-lived private connection credentials renew
  separately; signatures, identity binding, revocation and session scope remain
  enforced.

## Downloads

- `TaskContinuum-0.2.0-win-x64-setup.exe`: current-user Windows installer.
  Close Task Continuum, then install into the existing installation directory;
  uninstalling first is not necessary.
- `TaskContinuum-0.2.0-win-x64.zip`: manual archive. Extract the entire ZIP into a
  new directory before launching `TaskContinuum.exe`; do not replace files while
  the old application is running.
- `SHA256SUMS.txt`: SHA-256 checksums for the installer, ZIP, blockmap and update
  metadata.
- `latest.yml` and the installer `.blockmap`: versioned release/update metadata.
  Their presence does not make an unsigned installation eligible for automatic
  installation.

The desktop bundles Electron. Git is required for repository operations.
The standalone CLI requires Node.js 24. Native chats require a running,
authorized VS Code Agent Host; managed remote connections also require the
official Microsoft Dev Tunnel CLI and appropriate account permissions.

## Upgrade and compatibility

- **Every v0.1.1-or-earlier installation must upgrade manually.** Unsigned v0.2.0
  installations also continue to require manual upgrades. Signed automatic
  upgrades require the separately configured production signing workflow.
- Application ID, user-data location, device keys and original native sessions
  are preserved by installation. No message is automatically replayed and no
  replacement session is created.
- **Device-trust format is a breaking change.** Public grants require
  `lifetime: "until-revoked"`; old timestamp-expiry grants are rejected even if
  signed. There is no automatic conversion or bundled legacy migration tool.
  Update all participating desktops together. Already migrated workspaces retain
  their baseline and antirollback checks.
- If an old workspace has not been migrated, back up its configuration and
  profile and follow the documented separate-configuration rebuild process
  before enabling automatic links. Do not delete individual accepted records,
  reset device keys or reuse identities to bypass a revocation. A fresh setup
  requires explicit owner confirmation of existing chats.
